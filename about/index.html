About Weaver IT

Independent Web & Multiplayer Game Studio

Weaver IT is an independent game development studio based in Zagreb, Croatia. We specialize in building fast, accessible 3D multiplayer games that run natively in modern web browsers without requiring players to install launchers or large binaries.

What We Build

Our flagship project is Sinteza: Elemental Arena & Extraction MMO — a real-time 3D browser world featuring elemental combat, creature scanning, deckbuilding, Personal Sanctuary housing, and server-authoritative 1v1 ELO Arena matches.

Engineering Focus

  • Zero-friction access: Click a link and play in seconds on desktop web browsers.
  • Authoritative multiplayer architecture: Fair combat, anti-cheat validation, and server-side escrow for competitive duels.
  • Community-first updates: Rapid iteration driven directly by player feedback and playtesting.
